# Translation (Apple local / Google Cloud)

## Use

1. Select text in another app.
2. Press Command-C twice within 0.7 seconds. Holding Command while tapping C twice also works.
3. A compact floating result opens near the pointer and translates English into Traditional Chinese by default. Its header selects the target language; changing a language translates the current text again.
4. Click Edit to expand the same panel into a two-column editor: original on the left, translation on the right. The original, result, language choices and any in-progress translation are preserved while switching views.
5. Edit or paste the original, then click Translate (or Command-Return). Source language and optional automatic detection are available in this editor. Swap reverses explicit language choices and uses the existing result as the new original when available.
6. Compact view returns to the small result without discarding edits. Its height automatically follows the measured wrapped result, including paragraph breaks, with a 210-point minimum and a 720-point/screen-height maximum. Very long results remain scrollable. The top edge stays anchored where possible; the panel is kept within the visible display. Editor sizing is unchanged. Both presentations can still be resized manually; compact height is recalculated when its content or wrapping changes.
7. Copy translation explicitly when needed; Close or Escape discards its text and result. The panel can be moved by dragging its header background.

Clicking outside the compact result (including another Vorssaint window or another app) closes it and clears its text and in-flight work. Clicks inside the result, language/context menus, attached dialogs and the Accessibility Keyboard do not dismiss it. The two-column editor stays open when clicking elsewhere, so unfinished edits are not lost; Close or Escape still closes it explicitly.

Native titlebar dragging can deliver the panel's own mouse-down to both local and global AppKit monitors. The global dismissal path ignores events carrying the panel's own window number; being delivered globally does not by itself make a click external. This avoids closing at the end of a titlebar drag without disabling genuine outside-click dismissal.

Settings → General → Translation enables/disables the gesture and offers an Open translator button, which opens the editable two-column view directly. That button also works without Accessibility: paste/type text into Original or click Use copied text, then Translate. Accessibility permission is needed to observe the double-copy gesture in other apps. Neither keypress is intercepted or replaced.

The same settings card offers popup width (400–1,200 pt), text size (12–32 pt), Preview popup and Restore defaults (630 pt / 20 pt). Changes are saved as preferences and included in settings backups. Finishing a manual resize remembers the compact popup's width; automatic height changes and editor resizing do not overwrite it. Height still follows the translated content and remains bounded to the display. Opening a preview does not read the clipboard or start a translation.

## PDF line break cleanup

Settings → General → Translation → PDF line break cleanup is enabled by default. Before creating an Apple or Google translation request, it joins mid-sentence wrapped lines while retaining blank paragraph separators, list markers, indented/code-like text, table spacing and sentence-ending line breaks. Chinese/Japanese wrapped text joins without inserting spaces; visible word hyphens are retained. The complete prepared text is still sent as a single translation item. The editable original and system clipboard are unchanged. Turning the option off preserves the exact original text, including line endings, for subsequent translations.

Plain copied text does not carry PDF paragraph geometry. Cleanup is heuristic and also applies to manually pasted/typed text; disable it for poetry or other intentional line layouts. Paragraphs without blank lines or recognizable boundaries cannot always be distinguished from wrapping. This preference is included in settings backups. Changing it does not automatically retranslate or send text to Google.

## Google setup

Apple is the default. In Settings → General → Translation, select Google Cloud Translation, paste your Cloud Translation Basic API key into the secure field and click Save key. The existing saved key is never reloaded into the field. Save confirms local Keychain storage, not successful Google authentication; the first translation validates the key with Google. Remove key deletes this app variant's saved key. Developer and production variants use separate bundle-ID-based Keychain services.

Only the engine choice is a preference; the key is not stored in UserDefaults, settings exports, source files or Git. The unsaved field is cleared on leaving this settings page or changing engines. The app accesses Keychain off the main thread and does not log secrets or translations. macOS may request permission to access the saved Keychain item.

Choosing Google does not immediately send the existing text: invoke Translate or double-copy again. With Google selected, changing a source/target language or swapping languages explicitly translates the current text again. The panel shows its active engine and the editor displays the corresponding privacy notice. No silent engine fallback is performed.

Google requires an enabled Cloud Translation API, billing and a valid API key restricted to that API. Text is sent over HTTPS to the official Basic v2 endpoint, with the key only in `X-Goog-Api-Key`, never in the URL or JSON. NMT and plain-text format are explicit. Traditional Chinese maps to Google's `zh-TW` code. The network session is ephemeral, without cookies or caches, and refuses redirects. The complete prepared text is one query in one request; disabling PDF line break cleanup retains the original whitespace and line breaks. Requests exceeding 100,000 serialized JSON bytes are rejected locally, never split or truncated. No application-level automatic retries are made. Google counts whitespace toward character usage.

Google may charge for submitted text. Configure quotas and billing alerts in Cloud Console; alerts are not spending caps. Closing, cancelling, editing, changing engines, saving/removing a key or invoking a new translation cancels obsolete cloud work and suppresses stale results. Cancellation cannot retract text already received by Google or undo associated charges. This app does not save translation history, but Google's data processing policies apply to cloud requests.

## Scope and privacy

### Read aloud

The compact popup keeps the original above the translation in one scrollable area. On opening and when translation completes, it scrolls to the divider above the translation, retaining the normal 12-point spacing before its heading; users can then scroll back to the original without playback or unrelated UI updates pulling them back. A short result stops at the normal bottom scroll limit. Copy/Edit and Read original/Read translation share one footer row with matching large native buttons; reading stays on the right. Narrow widths use icons with tooltips to keep the same row. The editor has a speaker beside each text heading. Pressing the active button stops; choosing the other replaces playback. Editing, translating again, changing engines or languages, using another copy, closing the panel, locking the session, or stopping the service also stops obsolete speech. Nothing is read automatically.

Reading uses installed macOS AVSpeechSynthesizer voices with no Google request, API key, microphone permission, audio recording or speech history. Settings → General → Translation → Chinese speech chooses Cantonese (default) or Mandarin independently of Traditional Chinese writing. English prefers en-US, Japanese ja-JP; another installed accent of the same language may substitute. Automatic original-language selection uses local NaturalLanguage detection, which can be ambiguous for single words. Missing languages show a download instruction instead of silently using an unrelated voice; Cantonese and Mandarin never substitute for each other. Higher-quality installed voices are preferred, excluding novelty and personal voices. Voice quality depends on the installed system voices.

Reading voice settings provide one selector and Preview/Stop action for English, Cantonese, Mandarin and Japanese. Automatic preserves language/region matching before preferring higher installed quality; explicit choices can select another accent within the same language group. A removed or mismatched voice falls back to Automatic. Voice names show region and Basic/Enhanced/Premium quality. Download more voices opens macOS Read & Speak; its installed voice list refreshes on return and on available-voices notifications, without polling or silently downloading assets. The native reading-speed slider defaults to 0.5, is bounded to 0.25–0.65, and can reset to normal. Both popup reading and previews use those same settings. Preview uses fixed samples, preserves translation text/results/requests, and never submits Google usage. Choosing another voice or speed stops current playback; closing the voice settings stops only an active preview. Voice identifiers and speed are included in settings backups; unavailable voices safely fall back on another Mac.

### Google usage

With Google selected, Settings → General → Translation shows monthly submitted Unicode code points and request attempts, plus a Google Cloud Console link. Counting begins immediately before transport, after local validation and cancellation checks; failed or subsequently cancelled submissions remain counted as a conservative local estimate. Only month and aggregate counters are stored. Totals survive relaunches, roll over at midnight on the first of the month in Asia/Hong_Kong, and are excluded from settings backups. The settings display refreshes when opened, when submissions change, on app activation and once per minute while displayed. Past usage before this feature and usage from other apps/devices are not included. Google Cloud remains authoritative for actual usage and charges.

Usage updates serialize the read-modify-write and save immediately. Read-only snapshots read the complete stored dictionary without acquiring the writer's lock: settings notifications can synchronously wait for the main thread, so having the UI wait for that lock would deadlock before the HTTP request starts. This preserves existing totals and concurrent increments without deferred persistence.

Google usage reminder is enabled by default in the same settings section. At 450,000 local submitted characters (90% of the 500,000-character Basic NMT monthly reference allowance verified on 2026-10-25), a non-activating five-second HUD reminds once per Hong Kong calendar month. Settings retain a text/icon warning above the threshold. The toggle disables the HUD, not counting or translation; reenabling does not repeat a month already reminded. Existing over-threshold usage is checked at launch, and new submissions/settings changes check again without polling. The remembered reminder month survives relaunches and is excluded from backups, while the enabled preference is portable. No extra notification permission, network request, automatic retry or spending cap is added. Google's free credit can be shared with other usage; local estimates do not guarantee any remaining free quota. Reference: https://cloud.google.com/products/translate/pricing.

- Requires macOS 15 or later. Apple uses the on-device Translation framework; language downloads may require a connection and system approval. Google is an optional, explicitly selected cloud engine.
- Apple needs no API account. Neither engine saves translation history or text logs in this app, nor automatically replaces source text.
- Translation happens only after the double-copy gesture or an explicit button click. Single-copy and key autorepeat do not trigger it.
- The translator checks for a newly published clipboard item before automatically using it. Password-manager/private/transient clipboard markers are rejected before reading the text.
- Other clipboard/history apps still see ordinary native copies according to their own settings. The translator's explicit Copy translation button marks its output transient, so Vorssaint's clipboard history does not save it.
- Up to 40,000 characters per translation (Google additionally caps 40,000 billable Unicode code points and 100,000 serialized request bytes). Both Apple and Google receive the whole prepared selection as one translation item. Optional PDF cleanup joins wrapped lines before submission; turning it off retains the original text exactly. The engine controls the translated output's formatting. Oversized input shows an error rather than being split or truncated. Whole-input translation does not guarantee identical wording to the Google Translate website.
- Automatic detection can be ambiguous for individual words. Select the source language explicitly and retry when needed.
- Both language pickers expose Traditional Chinese, English and Japanese. Source-language automatic detection remains available. Engine language-pair availability is validated at runtime.

## Verification

Run `./build.sh --test-suite=translation --test-suite=clipboard --test-suite=preferences --test-suite=mixer --test-suite=settings --test-suite=keep-awake`.

For the native drag/dismissal regression, run `zsh Tests/TranslationDragIntegrationTests.sh` in a logged-in macOS graphical session with permission for synthetic mouse input. It compiles the real translation panel/service into an isolated fixture, checks eight physical drag sequences at different header offsets, and checks menu tracking, same-app and other-app outside clicks, and editor persistence. It never translates or reads clipboard contents or saved API keys. This opt-in GUI test is deliberately separate from the headless unit harness.

Run `zsh Tests/TranslationDragIntegrationTests.sh --usage-only` for the bounded usage-notification deadlock regression without windows. It compiles the real Google client and usage store, uses memory-only settings that synchronously notify a main-thread reader, and substitutes fake HTTP/key fixtures. It checks translation completion, same-thread reads, 64 concurrent increments and immediate persistence. A five-second watchdog fails the process rather than hanging if the deadlock returns; no personal settings, clipboard, credentials or network are accessed.

The same command also checks the real reminder service against isolated fixture preference keys and a captured HUD stub: exact threshold crossing, settings-notification feedback, disabled double-copy, repeated refreshes, recreation, disabled reminders and next-month eligibility. Passing `--render-usage=/absolute/existing/temp-directory` additionally renders the actual usage settings in Chinese/English, narrow/wide layouts and light/dark modes, without capturing the desktop.

Run `zsh Tests/TranslationDragIntegrationTests.sh --speech-only` for native speech lifecycle checks using the real service with a capturing synthesizer, installed voice metadata, synthetic text and isolated fixture preference keys. It produces no audible speech or paid translation requests. It checks repeat-to-stop, replacing playback, late callbacks, natural completion, edits, retries, engine/language changes, close, shutdown and missing-voice recovery. Add `--render-speech=/absolute/existing/temp-directory` to render the actual compact/editor controls in Chinese/English at minimum widths in light/dark modes, without capturing the desktop.

The same check covers explicit voice/rate settings in both preview and real reading, preview isolation and stop behavior, wrong-language or removed-voice fallbacks, separate Cantonese/Mandarin samples and unchanged Google totals. `--render-voice-settings=/absolute/existing/temp-directory` additionally renders the voice controls in Chinese/English, narrow/wide layouts and light/dark modes.

Add `--synthesize-speech` to check real English, Cantonese, Mandarin and Japanese synthesis using the installed voices. Generated audio buffers stay in memory and are not played or saved. Each language has a bounded twelve-second deadline. This optional check requires those language voices to be installed on the test Mac.

Run `zsh Tests/TranslationDragIntegrationTests.sh --scroll-only` to check initial result positioning in real native panels. It covers long originals, short/long results, manual scrolling preserved through fake speech updates, new results, editor/compact switching and reopening, without clipboard/key access or Google submissions. Add `--render-scroll=/absolute/existing/temp-directory` to render the actual initial result, manually revealed original and long-result start using fixture text.

The translation suite covers presentation sizing, localized compact/editor labels, timing, repeat suppression, app switching, stale clipboard metadata, private item rejection, limits, whole-selection translation including Unicode and whitespace, failed/cancelled async requests, and stale-result identity. Graphical checks use non-private fixture text to exercise the native Copy action, observed double-copy keys, real Apple translation, Edit/Compact state preservation, editing and retranslating, transient-marked output copying, and closing. Layout checks render the actual view in light/dark mode and at minimum sizes with long text. These integration checks require a logged-in graphical session.

Google unit checks use an injected fake transport and fake key only, covering fixed HTTPS destination, header-only credentials, plain-text NMT, language mapping, one unchanged query per complete selection, UTF-8/JSON byte limits, malformed results, HTTP/network failures, no automatic retries, missing credentials, cancellation and billable codepoint limits. A real authenticated Google translation must be verified after the user enters their own key in the installed app; tests never obtain a user's key through chat or terminal output.
